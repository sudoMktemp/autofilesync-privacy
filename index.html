Privacy policy

Auto File Sync

Effective date: July 23, 2026
Package: com.autofilesync
Publisher: LakeSide Bunny Inc

Scope

This policy covers the Android application Auto File Sync in its launch configuration. The app is local-first: cloud backup, Android OS backup, accounts, ads, analytics, and automatic crash reporting are not active in the launch release.

Data the app accesses on your device

Auto File Sync needs access to folders that you explicitly select through Android's Storage Access Framework. It may access or store locally:

  • Folder permission references for source and destination folders that you choose.
  • Schedule names and settings, including copy or move behavior, conflict rules, filters, cadence, and constraints.
  • File metadata needed to perform a sync, including names, sizes, modification dates, and folder positions.
  • Run history such as timestamps, status, counts, transferred bytes, and sanitized error messages.
  • Your Android notification-permission state.

The app does not request Android's broad all-files storage permission.

Data transmission and sharing

The launch version does not automatically transmit your schedules, folder references, file metadata, logs, analytics, crash reports, or other app data to LakeSide Bunny Inc or a developer-operated server. The production release does not request Android's INTERNET permission.

The app can export sanitized support logs only when you choose that action. Android then opens the system share sheet, and you choose the destination service. Exported logs are designed to remove raw file names, content URIs, paths, URLs, and obvious secrets. Once you send data to another app or service, that destination's privacy practices apply.

Retention and deletion

Schedules and run history remain in the app's local storage until you delete them, clear app data, or uninstall the app. You can revoke folder access in Android settings or by changing access in the selected storage provider. The app provides repair guidance when a saved folder permission is no longer available.

Because the launch version does not create accounts or store personal data on a developer-operated server, there is no server-side account or data-deletion process.

Security

Launch data is stored in the app's Android sandbox using Room. The app does not independently encrypt this local database at rest. Android OS backup is disabled because restored folder permissions are not reliable across devices. The app avoids logging raw folder URIs, secrets, and authentication material; exported support logs are sanitized before they are shared.

Future changes

Cloud backup code exists in the source repository but is disabled for the launch release. If cloud backup, accounts, analytics, crash reporting, or ads are introduced, this policy and the Google Play Data Safety declaration will be updated before that version is distributed.

Children

Auto File Sync is not designed for or directed to children.
