Auto File Sync

Auto File Sync is a local-first Android utility for scheduled folder copy and move jobs.

Contact LakeSide Bunny Inc: acrebyte@gmail.com

Before contacting support

Include the following information so we can understand the problem without asking for private files:

  • Android version and device model.
  • Auto File Sync version.
  • Storage provider type, such as device storage, removable storage, or a document provider.
  • Schedule type and whether the source or destination folder was recently changed or reselected.
  • The visible error code or repair message, if one is shown.

Protect your privacy

Do not send raw file names, folder paths, content URIs, passwords, API keys, or files unless you have independently decided that doing so is necessary. If support asks for diagnostics, use the app's user-triggered sanitized log export and review the exported text before sharing it.

Known limitations

  • Android WorkManager schedules background work and cannot guarantee exact wall-clock execution.
  • Folder permission can be revoked, moved, or invalidated after reinstall or device migration; reselect the folder when the app shows repair guidance.
  • Cloud backup is not active in the launch build.
  • Provider behavior can vary. Do not assume a removable-storage or cloud document provider is supported unless it has been tested for your device.
